# OverTheWire Natas Web Security Writeups

This repository contains my learning notes and writeups for the OverTheWire Natas wargame.

Natas focuses on server-side web security concepts such as:

- HTML source inspection
- HTTP headers
- Cookies
- Basic authentication
- Directory traversal
- Command injection
- SQL injection
- Cross-site scripting concepts
- Web application misconfiguration

## Purpose

This repository is for cybersecurity learning, documentation, and portfolio development.

## Disclaimer

This repository is only for educational and ethical cybersecurity practice.  
No real-world system is attacked or tested without permission.
